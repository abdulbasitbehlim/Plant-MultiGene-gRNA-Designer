# Support

For reproducible bug reports, include:

- project version and Python version;
- operating system;
- exact input mode and non-sensitive example input;
- accession/version and assembly/release shown by the app, when applicable;
- sequence SHA-256 from the exported provenance;
- full error traceback;
- whether the issue reproduces in Docker.

Scientific guide-design questions should distinguish computational compatibility from experimental validation. Do not include confidential, patient-identifiable or otherwise restricted sequence data in public issues.
